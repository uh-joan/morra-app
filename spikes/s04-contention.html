S0.4 — Contention Spike

Measures whether the v1 runtime mix (webcam CV worker + 2 playing videos + React UI + rAF loop) can hold 60fps, and probes browser capabilities relevant to the COOP/COEP ADR decision. All numbers on this page are live measurements taken in your current browser session — nothing here is fabricated or precomputed.

Operator instructions
  1. Serve this directory over HTTP (camera access needs a secure context: localhost is fine). Two options are provided:
    • python3 -m http.server 8000 from spikes/ — plain HTTP, crossOriginIsolated will read false.
    • python3 serve-coi.py (same directory) — sends Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp, so you can compare capability probes with crossOriginIsolated: true.
  2. Open http://localhost:8000/s04-contention.html.
  3. Capability probes and the decoder-count probe run automatically (or click their buttons if you skipped them).
  4. Click Start camera to grant webcam access and start real HandLandmarker inference, or click Run synthetic CV test to exercise the same worker/model pipeline without a camera (useful for headless verification).
  5. Use the duty-cycle buttons (Idle 5fps / Full-rate / Window burst) to switch CV load patterns and watch the fps meter, long-task counter, and per-mode p5/p50 table accumulate real samples. Leave each mode running 10–30s for stable percentiles.
  6. Click Export JSON / Export CSV to save the full result set for the ADR writeup.
