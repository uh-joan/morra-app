S0.1 — Finger-CV Spike

Throwaway test harness. MediaPipe HandLandmarker, raw-landmark finger counting, live scoring protocol. Not part of any package build.

Operator instructions (read before testing)
  1. Serve this directory over HTTP (not file://) — e.g. npx serve spikes or python3 -m http.server 8080 from spikes/, then open http://localhost:PORT/s01-fingers.html.
  2. Fill in tester name, lighting condition, and camera model (auto-filled after camera permission, editable).
  3. Click Start Camera, allow webcam access. Wait for status to say the model is ready and a mode badge appears (Worker+OffscreenCanvas or Main-thread fallback).
  4. Hold the digit key 1–5 down while throwing that many fingers at the camera; release the key when the throw is done. Repeat for many throws, mixing digits, especially 3 and 4.
  5. Watch the confusion matrix and the 3-vs-4 callout update live. Change lighting/tester and click Reset live stats to start a fresh matrix for that condition (all throws remain in the export regardless).
  6. Click Export CSV at the end of a session (or any time) to download every logged throw with metadata.

This harness never simulates or pre-fills throws — every row in the log and CSV comes from an actual keypress-held throw.
