# Llengües — design note for a later implementation

*Status: parked (2026-08-22). Explored, not built. Decision already taken by Janis: the
player's language (UI + what you shout) is ONE setting; the rival's language is a
second, independent one. Netflix without the third knob: you are the subtitles and the
dialogue at once; the rival is the dubbed audio.*

## The ask

Play in different languages — not only the UI, but the rival too. Shout Catalan against
a rival in Friulian or Sardinian. Two settings, both configurable:

| Setting | Controls | Default |
|---|---|---|
| **Jugador** (player language) | every UI string, the speech model that hears you, the number-word grammar, the calibration word prompts, the word the app echoes back («has dit "set"») | device/browser language if supported, else `ca` |
| **Rival** (rival language) | the clips the rival shouts, the word shown at his reveal, his taunt bubbles | = player language |

**Why player = UI + shout in one:** the screen and your own voice are the same person;
splitting them only creates a "Catalan UI, shouting Italian" state nobody asked for and
doubles the calibration/prompt matrix. The rival is a different person — that axis is
real.

## The rules never know (important)

`computeMicatioVerdict` (`packages/core/src/rules.ts`) sums fingers and compares two
numbers. A Catalan *set*, a Friulian *siet* and an Italian *sette* are all `7` by the
time they reach core. **No game-logic, scoring, AI, Classificació or telemetry change
anywhere** — all of those are numeric already. Language is entirely at the edges:
what the mic hears, what the speaker plays, what the screen says.

## What the code does today (with pointers)

- **One language, Catalan, baked in at ~21 references across 7 files** for the number
  words: `CATALAN_NUMBER_WORDS` / `NUMBER_TO_CATALAN_CALL` / `wordToNumber`
  (`packages/core/src/rules.ts`), `VOSK_GRAMMAR_WORDS` + `VOSK_MODEL_URL` +
  `RIVAL_VOICE_WORDS` + `RIVAL_VOICE_SUFFIX` (`apps/play/src/config.ts`), consumed by
  `vosk.ts`, `rivalVoice.ts`, `game.ts`, `render/gameCards.ts`, `render/rival.ts`.
- **Speech in:** Vosk, per-language acoustic model (`vosk-model-small-ca-0.4`, 43 MB,
  cached once per device by `modelCache.ts`) + a grammar restricted to the number words.
  `VoskCallRecognizer` already takes `modelUrl` and `vocabulary` as options — a language
  swap is configuration. `spikes/models/` already holds the **Italian** model too.
- **Speech out:** 10 rival clips (`dos…deu` + `tot`) generated by
  `spikes/rival-voice/generate.sh` from the macOS TTS voice «Jordi»; `RIVAL_VOICE_SUFFIX`
  is documented as "the single knob for swapping voice sets" (a spare `_gruff` set exists).
- **UI strings:** no i18n layer. Four homes: `apps/play/src/game/copy.ts` (247 lines,
  already a central module — the precedent to grow), `index.html` (~51 hardcoded Catalan
  lines), inline strings in screens / calibration / onboarding / firstrun / training,
  the four rivals' taunts in `pirate/cast.ts` (4 rivals × 7 reactions × ~2 lines), and —
  notably — **Catalan sentences generated inside core**: the Espill tells in
  `mirror.ts` («Quan mostres 3 dits, dius "set" el 40% de les vegades») and the mission
  goals in `missions.ts`.
- **Synonyms are per language:** Catalan ten = *deu* or *tot* (no «morra» call in
  Catalan — user is ground truth, see memory). Italian has *dieci* / *morra* / *tutta*.
  Each language owns its own synonym list.

## Feasibility per language — the honest table

| Language | As the RIVAL (clips + word table) | As the PLAYER (speech model + UI) |
|---|---|---|
| Català | ✅ shipped | ✅ shipped |
| Italiano | ✅ TTS voice exists → `generate.sh` in a minute | ✅ Vosk model already fetched; UI needs translation |
| Español / Français / English / Português | ✅ TTS voices exist | ✅ Vosk models exist; UI needs translation |
| **Furlan (Friulian)** | ⚠️ **no TTS voice on macOS** (nor on most services) → a human recording of 9–10 words, or a phonetic hack on an Italian voice | ❌ **no Vosk model.** Piggybacking the Italian model with Friulian words in the grammar is unreliable — words outside the model's lexicon fall to `[unk]` (*siet, vot, nûf*). Not a player language. |
| **Sardu (Sardinian)** | ⚠️ same as Friulian; plus a **dialect choice** — Logudorese *duos, tres, bator, chimbe, ses, sete, oto, noe, deghe* vs Campidanese *duus, tres, cuatru, cincu, ses, seti, otu, noi, dexi* | ❌ no Vosk model — rival only |

Number words for the rival tables (to be confirmed by native speakers — the
"second speaker" gate from the pending list applies here doubly):

- **Furlan:** 2 *doi* · 3 *trê* · 4 *cuatri* · 5 *cinc* · 6 *sîs* · 7 *siet* · 8 *vot* · 9 *nûf* · 10 *dîs*
- **Sardu (Logudorese):** 2 *duos* · 3 *tres* · 4 *bator* · 5 *chimbe* · 6 *ses* · 7 *sete* · 8 *oto* · 9 *noe* · 10 *deghe*
- **Italiano:** 2 *due* · 3 *tre* · 4 *quattro* · 5 *cinque* · 6 *sei* · 7 *sette* · 8 *otto* · 9 *nove* · 10 *dieci* / *morra* / *tutta*

So the headline scenario — **shout Catalan against a Friulian rival** — is exactly the
feasible one: the rival side needs recordings, not models.

## Architecture

One registry, `apps/play/src/language.ts` (+ the word tables in core so `wordToNumber`
stops being Catalan-only):

```ts
interface Language {
  code: "ca" | "it" | "es" | "fur" | "srd" | …;
  name: string;                        // endonym, for the picker
  numbers: Record<number, string>;     // canonical word per total 2–10 (reveal / echo)
  synonyms: Record<string, number>;    // every accepted word → number (grammar + parse)
  vosk?: { modelUrl: string };         // present ⇒ usable as PLAYER language
  clipSet?: string;                    // present ⇒ usable as RIVAL language (suffix/dir)
  strings?: Strings;                   // UI dictionary; present ⇒ selectable as UI
}
```

- `wordToNumber(word, lang)` / `canonicalCall(n, lang)` replace the Catalan constants.
- Vosk gets `modelUrl` + `vocabulary` from the player language; `modelCache` keys by URL
  already, so two languages = two cached models, each downloaded once.
- `rivalVoice.ts` loads the rival language's clip set; the reveal text uses the rival's
  canonical word; «has dit "…"» uses the player's.
- Prefs in localStorage (`morra_lang_player`, `morra_lang_rival`), URL flags for deep
  links and tests (`?lang=ca&rival=fur`), a picker on the tripulants screen for the
  rival and in the profile menu (or first-run) for the player. Changing the player
  language mid-session means a model swap — do it outside a match.
- The **player picker only lists languages with `vosk` AND `strings`**; the rival
  picker lists languages with `clipSet`. Feasibility is data, not code.

## Phases (each independently shippable)

1. **Rival language** — the registry, the word tables, clip sets, the rival picker,
   reveal word from the rival table. Italian first (TTS, free), then Furlan/Sardu as
   recordings arrive. Taunts stay in the player language ("dubbed audio, original
   subtitles") until translated. *~1 day of code; audio is the gate.*
2. **Player language — speech** — per-language Vosk model + grammar + calibration word
   prompts + the echo word. Italian first (model in hand), then Spanish. *~1–2 days.*
3. **Player language — UI** — extract every string (copy.ts, index.html, inline
   modules, cast.ts taunts, the core Espill/mission sentences) into dictionaries keyed
   by language; `t()` threading; `<html lang>` follows. *Days; mechanical; the least
   magic per hour but what makes a non-Catalan audience real.*

Phase 1 is worth doing on its own: it delivers the scenario that prompted this and
touches almost nothing.

## Guardrails

- Vosk grammar words must exist in the model's lexicon — unit-test each player language's
  synonym list against a recognizer smoke run, not just the table.
- The parity/integration harness injects Catalan words (`applyRecognizedWord(t, "set")`)
  — it must keep working unchanged with `lang=ca` as the default.
- Clip provenance: note voice/source per set (TTS voice name, or who recorded it).
- Names, scores, telemetry stay language-neutral — nothing to migrate in the
  Classificació or the collector.
- Native review before shipping any language: words, synonyms, dialect choice, taunts.
